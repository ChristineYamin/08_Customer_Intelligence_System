# 🎯 Project 8 : Customer Intelligence System

A data-driven customer segmentation system built using **RFM Analysis** and **K-Means Clustering**, with an interactive **Streamlit dashboard** to deliver actionable business insights.

---

## 📌 Project Overview

Understanding customer behavior is essential for effective marketing and business growth.

This project segments customers into distinct groups based on their purchasing behavior and provides **strategic recommendations** for each segment.

---

## 🧠 Key Objectives

- Analyze customer behavior using RFM (Recency, Frequency, Monetary)
- Segment customers using K-Means clustering
- Visualize customer groups and patterns
- Provide actionable marketing strategies for each segment
- Build an interactive dashboard for business use

---

## 🧩 Methodology

### 1. RFM Analysis
Customers are evaluated based on:

- **Recency (R):** How recently a customer made a purchase  
- **Frequency (F):** How often a customer makes purchases  
- **Monetary (M):** How much a customer spends  

---

### 2. Data Preprocessing
- Aggregated transactional data into customer-level features
- Applied **log transformation** to reduce skewness
- Scaled features using **StandardScaler**

---

### 3. K-Means Clustering
- Used the **Elbow Method** to determine optimal number of clusters
- Applied **K-Means algorithm** to segment customers
- Evaluated clustering performance using **Silhouette Score (~0.33)**

---

### 4. Cluster Interpretation
Clusters were analyzed based on average RFM values to understand customer behavior patterns.

---

### 5. Business Strategy Mapping
Each segment is mapped to a **marketing strategy**, such as:
- Retention strategies for high-value customers
- Re-engagement campaigns for at-risk customers
- Growth strategies for new customers

---

## 📊 Dashboard Features (Streamlit)

- 📌 Key metrics overview
- 📊 Customer segment distribution
- 🔍 Interactive segmentation visualization (R vs M)
- 💡 Strategic marketing recommendations by segment
- 📂 Raw dataset exploration

---



## 🛠️ Tech Stack

- **Python**
- **Pandas & NumPy**
- **Scikit-learn**
- **Matplotlib & Seaborn**
- **Streamlit**
